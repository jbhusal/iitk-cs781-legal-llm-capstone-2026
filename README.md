# iitk-cs781-legal-llm-capstone-2026
Code for my CS781 IITK LLM capstone: four legal language models (A, B, C, D) pretrained from scratch in Phase 1, then adapted to six legal NLP tasks (NER, rhetorical roles, judgment prediction, statute identification, summarisation, case retrieval) using LoRMA, QLoRA, IA³, adapters and knowledge distillation. Kaggle 2× T4, official data only.
